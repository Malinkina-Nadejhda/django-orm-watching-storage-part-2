# Веб-сайт системы контроля доступа (Хранилище пропусков)

Локальный веб-сайт для охранников и администраторов, позволяющий в реальном времени отслеживать посетителей в хранилище и просматривать историю их визитов.

**Как установить:**

- Клонируйте репозиторий.
- Должен быть установлен `Python` версии 3.11 или выше.
- Используйте `pip` для установки зависимостей:

```bash
pip install -r requirements.txt
```

## Настройка окружения

1. Создайте файл `.env` в корневой папке проекта.
2. Добавьте в `.env` реальные данные для подключения к базе данных, секретный ключ Django и режим отладки:
   ```env
   DB_NAME=имя_вашей_базы
   DB_USER=ваш_логин
   DB_PASSWORD=ваш_пароль
   DB_HOST=адрес_хоста
   DB_PORT=5432
   SECRET_KEY=ваш_секретный_ключ_django
   DEBUG=True
   ```

## Запуск сайта

В терминале выполните команду:

```bash
python manage.py runserver 127.0.0.1:800
```

После успешного запуска откройте любой браузер и перейдите по локальному адресу:

[http://127.0.0](http://127.0.0)

## Возможности сайта и страницы

### 1. Главная страница (Список сотрудников)
Отображает полный список всех активных карт доступа и их владельцев. Каждое имя является кликабельной ссылкой для перехода к личной истории посещений.

### 2. Кто в хранилище прямо сейчас
Показывает таблицу людей, которые зашли в хранилище и еще не покинули его, а также высчитывает точное время их нахождения внутри.

### 3. Личная история посещений
Страница, которая открывается при клике на конкретного сотрудника. Она выводит полную историю его визитов, рассчитывает длительность каждого посещения, а также автоматически подсвечивает слишком долгие и подозрительные визиты (длящиеся более 1 часа).
